DEP-3: AI Policy
=============================

| **Author(s):** Anton Hoyer
| **Status:** Draft
| **Type**: Process
| **Created:** 20.11.2026


Motivation
----------
The pyfar ecosystem is confronted with an increasing number of AI-assisted or
fully AI-created contributions. To ensure long term maintainability and code
quality a uniform and comprehensive AI policy is proposed.

Scope
-----
The proposed guidelines apply to pull requests and issues, including
communication (comments, descriptions, titles) and written code.

Guidelines
----------

“AI” herein refers to generative AI tools like large language models (LLMs)
that can generate, edit, and review software code, create and manipulate
images, or generate human-like communication.

Responsibility
~~~~~~~~~~~~~~

Contributions require a human participator. The contributor is responsible
for any code that is being submitted to pyfar's repositories. A contributor
should be able to understand and explain the code submitted, it is prohibited
to commit unverified AI-written code. Also it is recommended to not use AI to
create descriptions for contributions.

Disclosure
~~~~~~~~~~

If AI has been used to assist the development of a contribution it is
mandatory to add a disclosure to the descriptions, explaining to what extent
AI was used and that the changes were reviewed by a human.

Code Quality
~~~~~~~~~~~~

Contributors are expected to submit code that meets pyfar's standards specified
in the `contribution guidelines <https://pyfar-gallery.readthedocs.io/en/latest/contribute/index.html>`_.
We will reject pull requests that we deem to be "AI slop". Also keep the
pull requests' size manageable for the reviewers and maintainers.

Copyright
~~~~~~~~~

All code in pyfar is released under the MIT license.
Contributors to pyfar license their code under the same license when it is
included into pyfar’s version control repository. That means contributors must
own the copyright of any code submitted to pyfar or must include the MIT
compatible open source license(s) associated with the submitted code
in the patch. Code generated by AI may infringe on copyright and it is the
submitter’s responsibility to not infringe. We reserve the right to reject any
pull requests, AI generated or not, where the copyright is in question.

Communication
~~~~~~~~~~~~~

When interacting with developers (forums, discussions, issues, pull requests,
etc.) do not use AI to speak for you, except for translation or grammar
editing. If the developers want to chat with a chatbot, they can do so
themselves. Human-to-human communication is essential for an open source
community to thrive.

AI agents
~~~~~~~~~

The use of an AI agent that writes code and then submits a pull request
autonomously is not permitted. A human must check any generated code and
submit a pull request according to the ‘Responsibility’ section above.
