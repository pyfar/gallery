====================
Projects Using Pyfar
====================

The *Projects Using Pyfar* section on `pyfar.org <https://pyfar.org>`_
showcases the community's work and helps others discover projects that use
pyfar. We welcome all kinds of projects, including Python packages, other
software, research projects, creative work, educational resources, and
tutorials. If your project uses pyfar, we would love to hear about it!

Add your project
----------------

To suggest a project, choose either of the following options:

* Open an `issue <https://github.com/pyfar/gallery/issues/new>`_ in the
  gallery repository.
* Submit a `pull request <https://github.com/pyfar/gallery/pulls>`_ that adds
  your project to the *Projects Using Pyfar* section in ``docs/index.rst``.

Please include:

* The name of your project.
* A link to its website, repository, or another page where people can learn
  more about it.
* A one-sentence description of the project.
* A brief explanation of how the project uses pyfar.

Once the maintainers have reviewed the submission, your project will be added
to the list.
